# 큐브 일러스트 제작소

큐브 교본·강의 자료에 넣을 그림을 브라우저에서 바로 만들고 PNG로 내보내는 도구입니다.
설치 없이 웹에서 쓸 수 있고, 파일 하나(`cube-illustrator.html`)로 이루어진 순수 HTML/JS라 내려받아 오프라인으로 써도 됩니다.

**👉 바로 쓰기: https://pauleum00-sketch.github.io/cube-illustrator/**

## 기능

### 큐브 색칠 (입체 뷰)
- 스티커를 클릭·드래그로 색칠. 같은 색을 다시 누르면 회색으로 되돌아감
- 8색 팔레트 (큐브 6색 + 핑크 + 회색)
- 큐브 바깥 빈 곳을 드래그하면 자유 회전, 놓으면 반듯한 각도로 자동 정렬(끌 수 있음)
- X·Y·Z 각도를 슬라이더/숫자로 정밀 조절, 마음에 드는 각도는 슬롯 1·2·3에 저장
- 드래그 잠그기: 맞춰둔 각도가 실수로 흐트러지지 않게 보호
- 보조면: 화면에서 가려진 면을 펼쳐서 함께 표시 (면이 드러나면 자동으로 사라짐)
- 투명 모드: 앞면을 반투명하게 만들어 뒷면 스티커가 비쳐 보이게
- 화면 표시는 고정 프레임이라 회전 중에도 큐브 크기·위치가 튀지 않음

### 탑다운 뷰 (OLL·PLL 도해)
- 윗면 9칸 + 옆면 윗줄 12칸을 위에서 내려다본 표준 도해 형식
- 입체 뷰와 같은 큐브를 공유 — 어느 쪽에서 칠해도 함께 반영

### 회전기호 도해
- `R U2 R' U' R U R'` 같은 회전기호를 입력하면 수별 도해를 자동 생성
- 바깥층·두 층(r, u, …)·가운데층(M, E, S)·큐브 전체(x, y, z) 지원
- `U' U'` → `U'2` 자동 정리, 뒤쪽·안쪽이라 보이지 않는 `B`·`S`는 점선 화살표로 표현
- 크기 조절(55%~145%) 후 내보내기

### 공통
- PNG 저장·클립보드 복사 (3배 해상도, 배경 투명 옵션)
- 작업 내용은 브라우저에 자동 저장 — 새로고침해도 그대로 유지
- 입체·탑다운·회전기호가 같은 투시각을 써서 교본 안에서 그림 각도가 일관됨
